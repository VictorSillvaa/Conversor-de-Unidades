# Documentação do Projeto: GameStore

Este projeto consiste em uma **Landing Page de E-commerce** desenvolvida para uma loja de jogos digitais chamada **GameStore**. O foco principal é a exibição de produtos em destaque, proporcionando uma experiência de navegação limpa e direta.

---

## 🛠 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica para melhor acessibilidade e SEO.
- **CSS3**: Estilização modularizada, utilizando técnicas modernas de layout.
- **Google Fonts**: Integração das fontes *Inter* e *Poppins* para um design profissional.
- **JavaScript**: Lógica para interatividade (menu responsivo e atualização dinâmica de elementos).

---

## 📂 Estrutura de Arquivos

O projeto segue uma arquitetura modular para facilitar a manutenção:

- `index.html`: Estrutura principal da página.
- `css/`: Pasta contendo arquivos segmentados:
  - `variables.css`: Definição de cores e tipografia.
  - `components/`: Estilos específicos para `btn`, `navbar`, `card` e `footer`.
- `js/`: Pasta para a lógica da aplicação (`main.js`).

---

## 💻 Principais Funcionalidades

1. **Navegação Responsiva**: Menu com suporte a dispositivos móveis (hambúrguer).
2. **Grade de Produtos**: Exibição em grid utilizando `cards` para organizar as informações de cada jogo (capa, título, categoria e preço).
3. **Chamadas para Ação (CTA)**: Botões estilizados para diferenciar produtos em destaque de ofertas secundárias.
4. **Navegação Interna**: Links de âncora que levam o usuário diretamente para as seções de "Destaque" e "Suporte".
5. **Rodapé Informativo**: Seção contendo políticas da empresa, informações de contato e copyright atualizado automaticamente.

---

## 🚀 Como Executar

1. Clone o repositório para sua máquina local.
2. Certifique-se de que a estrutura de pastas (imagens, CSS e JS) está correta.
3. Abra o arquivo `index.html` em qualquer navegador moderno.
